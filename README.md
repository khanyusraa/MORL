To run this program:
1. Download the requirements from the provided text file.
2. Select the environment you want to run, i.e dst_experiment.py or minecart_experiment.py
   If DST, input the desired level of stochasticity as well as the desired algorithm
     e.g python3 dst_experiment.py high eupg
   If Minecart, input the desired level of stochasticity, algorithm, chunk size, index number of the current run and total timesteps to train for
     e.g python3 minecart_experiment.py high eql 200000 1 800000
